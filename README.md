# InventorySystem

A modern backend-focused inventory and order management platform built with ASP.NET Core and microservices architecture principles.

## 🚀 Project Overview

InventorySystem is a scalable and containerized backend system designed for managing products, orders, and authentication workflows.

The project is being developed to demonstrate modern backend engineering concepts including:

* ASP.NET Core Web APIs
* Microservices architecture
* Docker & containerization
* SQL Server integration
* API Gateway
* Authentication & Authorization
* Monitoring & logging
* Message brokers and asynchronous communication

---

## 🛠️ Tech Stack

* ASP.NET Core (.NET 8)
* C#
* SQL Server
* Docker & Docker Compose
* Entity Framework Core
* RESTful APIs

### Planned Technologies
